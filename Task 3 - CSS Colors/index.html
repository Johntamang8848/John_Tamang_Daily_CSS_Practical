Color Formats

CSS colors can be written in several formats, including transparent color values.

Named color

Tomato is a built-in CSS color name.

tomato

HEX

A six-digit hexadecimal value sets red, green, and blue.

#315C9B

RGB

Red, green, and blue channels use values from 0 to 255.

rgb(34 125 112)

RGBA

The alpha channel controls transparency.

rgba(109, 73, 160, .78)

HSL

Hue, saturation, and lightness describe the color.

hsl(38 88% 53%)

HSLA

HSL with alpha blends this accent with the background.

hsla(190, 70%, 42%, .68)
